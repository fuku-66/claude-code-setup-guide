03 / Copy & paste

最初は、この頼み方でOK

このフォルダの中を確認してください。 目的：〇〇を作りたいです。 私は初心者なので、難しい言葉は簡単に説明してください。 変更してよいのは、このフォルダの中だけです。 元ファイルは削除しないでください。 作業後に、保存場所と確認結果を教えてください。
目的・範囲・完成・確認をセットにする

04 / Safety

初心者が守るのは、4つだけ

パスワードや秘密情報を貼らない
最初はコピーしたデータで試す
削除・送信・公開は実行前に確認
最後にファイルを自分でも見る
迷ったときは「まだ変更せず、まず説明して」と頼む
